# Практическая работа «Live-центр мониторинга» (SignalR)

Отдельный ASP.NET Core 8 проект по PDF «Практическая работа (6)». Реализованы задания 1–5 и три дополнительных уровня.

## Запуск

Нужен .NET 8 SDK. Откройте терминал в `LiveMonitor` и выполните:

```bash
dotnet run
```

Откройте <http://localhost:5080/> в двух или трёх вкладках. Браузеру нужен доступ к CDN `cdn.jsdelivr.net` для загрузки SignalR JavaScript клиента. Серверу дополнительные NuGet пакеты не требуются: SignalR входит в ASP.NET Core.

## Что работает

- Подключение и отключение пользователей, общая лента событий и широковещательные сообщения.
- Комнаты с адресными сообщениями. При переходе в другую комнату клиент исключается из старой группы.
- Счётчик онлайн и полный список подключений с их комнатами; нажатие на участника подставляет его ID для приватного сообщения.
- Автоматическое переподключение с задержками 0, 2, 5, 10 и 30 секунд и повторный вход в прежнюю комнату.
- Приватные сообщения через хаб и внешние уведомления через HTTP POST с отправкой в SignalR через `IHubContext`.
- Индикатор «печатает…» для других участников комнаты с задержкой отправки 500 мс и скрытием через 2 секунды.
- Поток случайных чисел каждые 500 мс с живой диаграммой и отменой подписки.

Хаб: `/hubs/monitor`. HTTP-запросы для системной, комнатной и приватной рассылки приведены в [`LiveMonitor/LiveMonitor.http`](LiveMonitor/LiveMonitor.http). CORS настроен для `http://localhost:3000`.

## Ключевые файлы

- `LiveMonitor/Hubs/MonitoringHub.cs` — методы и события SignalR, группы, приватная отправка, набор текста, поток.
- `LiveMonitor/Services/ConnectionRegistry.cs` — singleton словарь подключений и отправка через `IHubContext`.
- `LiveMonitor/Program.cs` — SignalR, CORS, статические файлы, HTTP-эндпоинты.
- `LiveMonitor/wwwroot/index.html` и `LiveMonitor/wwwroot/js/app.js` — интерфейс и клиентский код без jQuery.

## Проверка

Проект собран на .NET 8 без ошибок и предупреждений; JavaScript прошёл синтаксическую проверку. При проверке двумя SignalR подключениями подтверждены счётчик онлайн, широковещание, изоляция комнат, приватные сообщения и подтверждение отправителю, индикатор набора текста, доставка системного, комнатного и приватного HTTP-уведомлений и получение элемента потока. Главная страница и ресурсы отдаются с HTTP 200; CORS preflight для `http://localhost:3000` отвечает с разрешённым origin.
